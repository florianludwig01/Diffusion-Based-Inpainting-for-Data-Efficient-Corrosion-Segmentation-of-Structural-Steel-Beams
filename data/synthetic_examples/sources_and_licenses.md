## Synthetic images and annotations

The example subset contains:

- 12 synthetic corrosion images generated using FLUX.1 Fill Dev in `Synth-FLUX/images/`.
- 10 synthetic corrosion images generated using Juggernaut XL v9 (SDXL) in `Synth-SDXL/images/`.
- Corresponding corrosion annotations in each dataset's `labels/` directory.

All synthetic images were generated by inpainting the authors' photographs. They contain AI-generated corrosion and should not be interpreted as photographs of actual corrosion.

Annotations use YOLO segmentation format, with class 0 denoting corrosion. Each annotation file has the same basename as its corresponding image. These annotations describe corrosion regions; they are not the masks used for inpainting.
